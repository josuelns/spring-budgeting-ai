# spring-budgeting-ai

> Registrar despesas e receitas por voz, com resposta natural, sem depender de formulários manuais.

## Problema

Registrar despesas e receitas por voz, com resposta natural, sem depender de formulários manuais.

## Solução

API Spring Boot com Spring AI: Whisper transcreve o áudio, GPT com tool calling persiste transações e devolve resposta em voz. Autenticação OIDC via Keycloak, Redis para cache e stack completa containerizada (MySQL, Redis, Keycloak) com Docker Compose.

## Stack

- Java
- Spring Boot
- Spring AI
- Keycloak
- MySQL
- Redis
- Docker
